# 共通仕様

## ✳️ アプリのアップデート

### ✏️ アップデートのチェック

- アプリ本体は <https://github.com/treetips/tree-voice-assistant/releases/latest/download/update-info.json> を確認する。
- ツールは <https://github.com/treetips/tree-voice-assistant/releases/download/tools-latest/tools-info.json> を確認する。
- 起動時はダイアログを出さず、不足ツールの準備後にヘッダー下の更新ステータスピルへ結果を反映する。
- About画面の `アップデートを確認` ボタンとメニューバーの `更新を確認` は、アプリ本体を同じ手動確認経路で扱う。
- 手動確認で更新なし・失敗時はダイアログで通知する。失敗時はヘッダー下の更新ステータスピルを変更しない。

### ✏️ ヘッダー下の更新ステータスピル

- 詳細ペインのヘッダー下の右上に、アプリとツールを統合した1行のカプセル型 Liquid Glass を固有サイズで表示する。ツールバーへは配置せず、全幅化もしない。ピルの高さは本文のレイアウトとして確保する。
- 左端に円形背景の状態アイコン、中央にステータス本文、右端に操作ピルと円形の閉じるボタンを置く。
- 更新ありの文言は次の3種類とする。

| 更新の状態 | 本文 | 操作ピル |
| ---------- | ---- | -------- |
| アプリのみ | アプリの更新があります | ダウンロード |
| ツールのみ | ツールの更新があります | インストール |
| 両方 | アプリとツールの更新があります | インストール |

- 操作ピルを押すと確認ダイアログを挟まず、利用可能な更新を開始する。本文をクリックして開始することはない。
- 両方ある場合はツールを更新してからアプリのダウンロードへ進む。ツール更新に失敗した場合はアプリ更新を開始しない。
- 更新なし・更新あり・失敗時は閉じるボタンで非表示化できる。実行中と再起動待ちは、進捗や再起動操作を失わないよう閉じるボタンを表示しない。
- 更新なしは `アップデートは有りません` と表示し、閉じるボタンまたは10秒後に非表示化する。

### ✏️ アプリ更新の場合

1. 青い更新ステータスピルの `ダウンロード` からZIPのダウンロードを開始する。
2. ダウンロード中は円形の進捗表示と百分率を表示する。総バイト数が不明な場合は不確定のスピナーを表示する。
3. SHA-256検証、展開、ステージングの各段階を同じステータスピルに表示する。
4. ステージングが完了すると緑の `アップデート完了` ステータスピルへ切り替わる。この時点では `/Applications` のアプリを置換しない。
5. `アプリ再起動する` を押した後、ステージング済みアプリを `/Applications/TreeVoiceAssistant.app` へ配置し、別プロセスで起動して旧プロセスを終了する。
6. 再起動せずに終了した場合、次回起動時に `~/Library/Application Support/tree-voice-assistant/updates` を掃除する。

### ✏️ ツール更新の場合

- ツールは `uv`、`mlx-audio` のプロジェクト定義・lockfile、`Irodori-TTS` のソース・プロジェクト定義・lockfileを個別に更新する。
- Python仮想環境と音声モデルは初回利用時に取得する。ツール更新だけでアプリを再起動しない。
- 更新中はSTT/TTSの新規実行を無効化し、実行中はツール更新を開始できない。
- ダウンロード中は円形の進捗表示と百分率を表示し、検証・展開・準備中は段階名と対象ツール名を表示する。
- 失敗時は赤いステータスピルと `再実行` を表示し、完了済みツールの記録を残して未完了分だけをやり直す。閉じるボタンで通知を消すこともできる。

### ✏️ 失敗時

- ダウンロード、検証、展開、配置の失敗時は赤いステータスピルへ切り替わり、エラーダイアログで理由を通知する。`再実行` または閉じるボタンで操作できる。
- アプリの起動だけに失敗した場合は、再ダウンロードせず緑のステータスピルから起動を再試行できる。
