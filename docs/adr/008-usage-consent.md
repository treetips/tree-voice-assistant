# 利用上の注意・同意シート

- 初回起動時に利用上の注意と同意チェックをモーダルシートで表示し、
  同意しない限り閉じられないようにする（案A）。
  - タイトル・本文・チェックボックス・「同意して続行。」で構成する。
  - 表示言語は設定言語（未指定時はシステム言語）に従い、日英で切り替える。
- 同意済みの状態は `settings.json` とは別の専用ファイルに保存する。
  - パス: `~/Library/Application Support/tree-voice-assistant/agreement.json`
  - 中身: `{"agreeDate": "yyyy-MM-dd HH:mm:ss"}`（同意日時）
  - ファイルが存在すれば同意済みとして扱い、アプリのアップデートでも
    再表示しない。
- About画面の Copyright の下に「同意事項を再表示」を置き、いつでも
  閲覧できるようにする。再表示時は同意チェックを要求せず、閉じる操作のみ行う。
- 文言は開発者が確定した原文を `Localizable.xcstrings` に日英で登録する。
  - リポジトリの `LICENSE` は別製品の文言のため、今回は触らない。
