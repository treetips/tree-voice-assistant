# 更新ステータスピルの非表示時にレイアウトを保持する

## ステータス

- 承認済み (Accepted)
- 影響範囲: 更新UI
- 関連: ADR 026

## 背景・課題

更新なしピルは閉じるボタンまたは10秒後に非表示になります。非表示時に `EmptyView` へ切り替えると、安全領域の高さまで縮み、詳細コンテンツが上へ移動して画面がガクッとなりました。

## 決定

- 更新ステータスピルの非表示状態は、更新なしピルを `.hidden()` にした同じレイアウトを保持する。
- ピルの表示・非表示が切り替わっても、安全領域の高さと詳細コンテンツの位置を変えない。
- 更新なしピルの自動非表示と閉じるボタンの動作は変更しない。

## 代替案

- 非表示状態を `EmptyView` にする
  - 却下: 安全領域が畳まれ、本文の位置が変わるため。
- 更新ピルを安全領域から外して重ねる
  - 却下: ピルと入力エリアが重なるため。
- 非表示状態に固定の数値だけを予約する
  - 却下: 文字サイズや表示言語に応じたピルの高さを再現しにくいため。

## 結果

- 更新なしピルが消えても、本文や入力エリアが上へ移動しなくなった。
- 文字サイズや表示言語が異なっても、非表示状態は更新なしピルと同じ高さを確保する。
- 実装箇所: `TreeVoiceAssistant/TreeVoiceAssistant/Features/Updates/UpdateCardsToolbar.swift`。
