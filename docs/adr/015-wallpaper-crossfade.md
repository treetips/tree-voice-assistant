# 背景画像の切替を0.5秒のクロスフェードにする

- ステータス: Accepted
- 影響範囲: `App/RootView.swift`
- 関連: tree-image-optimizer ADR 0028（背景画像の切替を0.5秒のクロスフェードにする）、ADR 014（設定画面に背景画像のシャッフル機能を追加する）

## 背景

背景画像のシャッフル（ADR 014）は `wallpaper` を更新して `Image` の内容を
張り替えるのみで、切り替えが一瞬で完了する。自然な切替見た目が求められた。

単純に `.transition(.opacity)` を付けて新旧を交差フェードするだけでは、
中間点で新旧のどちらも半透明になり（各50%）、設定の背景色が約25%透ける。
暗い背景色のとき、切替中の一瞬だけ画像が濁って見える。

## 決定

- `RootView.backgroundImage` を2層構成にする。
    - 前面: 現在の壁紙。`.id(url)` で切替のたびに別Viewとし、
      `.transition(.opacity)` でフェードインする。
    - 背面: 直前の壁紙。切り替え時に不透明のまま裏へ置き、フェード中は
      背景色が透けないようにする。
- フェードは `easeInOut`・0.5秒。定数 `wallpaperCrossfadeSeconds` とし、
  設定項目にはしない。
- 適用対象は背景画像のすべての切り替え（シャッフル・プルダウンでの手動選択・
  「背景無し」）。「背景無し」への切替は裏面を張らず、旧画像のフェードアウト
  だけで背景色へ戻す。
- フェード完了後は裏面をフェードしながら解放する。
  不透明度が1未満の設定で、解放の瞬間に透明度が跳ねるのを防ぐ。
- フェード中・裏面解放中（切替から約1秒）の追加切り替えはフェードを打ち切り、
  即時切替にする。この期間に裏面を張り替えると、裏面と進行中のフェードアウト
  残骸の内容が食い違い、画像がガタつくため。
- 起動直後の初回表示は従来どおり即時表示する。アニメーション発火の起点となる
  値の変化がないため。

## 代替案

- 新旧を `.transition(.opacity)` だけで交差フェードする
    - 却下: 中間点で背景色が透け、自然さが損なわれる。
- フェード時間を設定項目にする
    - 却下: 固定の0.5秒で要件を満たすため、UIと永続化を増やさない (YAGNI)。
- フェード中の追加切り替えも連続してフェードさせる
    - 却下: 連続切替のたびに裏面と残骸の非整合が生じてガタつく。
      打ち切って即時切替にするほうが自然に見える。

## 結果

- 背景画像の切り替えが、すべての経路で0.5秒のクロスフェードになった。
- 実装箇所: `TreeVoiceAssistant/TreeVoiceAssistant/App/RootView.swift` のみ。
- 単体テストは追加していない。変更がアニメーションのみのView変更で、
  View検査の基盤（ViewInspector等）もないため、lint・整形・ビルド・既存テスト
  で確認する。フェードの見た目は実機で確認する。
